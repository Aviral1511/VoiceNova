# 🚀 VoiceNova — AI Voice Assistant

> A smart and customizable voice-controlled assistant using React, Node.js, Gemini API, Web Speech API & MongoDB.

VoiceNova can listen, think, respond, speak, and perform tasks like searching the web, opening websites, answering questions, storing history, and personalising user experience.

---

## ✨ Features

- **Voice Input** using Web Speech Recognition API
- **Text-to-Speech Output** using SpeechSynthesis
- **Gemini API Integration** for conversational replies
- **Login & Signup Authentication** using JWT
- **Custom Assistant Personalization** (Image/Name/Language)
- **Command Execution** (open YouTube/Google/web apps)
- **History Tracking** for conversations

## 📦 Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/your-username/voicenova.git
cd voicenova
```

### 2️. Install dependencies

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Backend:

```bash
cd backend
npm install
npm start
```

### 3️. Add environment variables to backend/.env

```bash
MONGO_URI=your-mongodb-url
JWT_SECRET=your-secret
GEMINI_API_KEY=your-key
```
